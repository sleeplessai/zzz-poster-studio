关于 ZZZ Poster Studio
ZZZ Poster Studio v1.0.0
基于《绝区零》官方贴画的海报、黑板报与拼贴剪报创作小工具
📦 开源仓库 GitHub ↗
作者：爱打电动的柚蜜小姐
欢迎 Star ⭐、贡献二创脑洞与交流分享！
🎨 主要功能
使用官方高清贴图素材，轻松自由创作潮流游戏海报、概念拼贴画与视觉简报。
⚡ 技术架构
Vanilla JS + Canvas + PWA
使用 Antigravity 与 Gemini 3.7 Flash 模型协同开发完成。
